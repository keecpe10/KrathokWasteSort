# KrathokWasteSort

บล็อกภาษาไทยสำหรับแข่งหุ่นยนต์อัตโนมัติ **"แยกขยะ" รุ่นอายุไม่เกิน 12 ปี** (ศรีสะเกษโรโบติกส์ 2026)
ใช้กับหุ่น KidsBIT ร่วมกับส่วนขยาย [KrathokKidsBit](https://github.com/keecpe10/KrathokKidsBit) (ติดตั้งให้อัตโนมัติ)

## สนามและภารกิจ

```
 [ถังดำ]            [START]            [ถังขาว]
    |                  |                  |
 1  +--------+---------+--------+---------+     แถว 1  (ใกล้ START)
    |        |         |        |         |
 2  +--------+---------+--------+---------+     แถว 2
    |        |         |        |         |
 3  +--------+---------+--------+---------+     แถว 3
    |        |         |        |         |
 4  +--------+---------+--------+---------+     แถว 4
   คอลัมน์ 1   2        3        4        5
                       |
                (จุดวางกระป๋อง)
```

- เส้นแนวนอนห่างกัน 200 มม. เส้นแนวตั้งห่างกัน 500 มม.
- สิ่งกีดขวาง 4 ชิ้นวางทับทางแยก (กรรมการสุ่มก่อนเขียนโปรแกรม) หุ่นจะไม่วิ่งผ่านทางแยกนั้นและ**หาทางอ้อมเอง**
- กระป๋อง 8 ใบ (ขาว 4 ดำ 4) วางทีละใบที่จุดวางกระป๋องตามลำดับสีที่สุ่มได้
- หุ่นหยิบกระป๋อง ยกขึ้น นำไปวางถังตามสี ครบ 8 ใบแล้วกลับเข้ากรอบ START หยุดนิ่ง

## บล็อก (หมวด **แยกขยะ**)

| กลุ่ม | บล็อก |
|---|---|
| ตั้งค่าสนาม | มีสิ่งกีดขวางที่ แถว _ คอลัมน์ _ · ล้างสิ่งกีดขวางทั้งหมด · ลำดับสีกระป๋อง ใบที่ 1-8 · ถังดำอยู่คอลัมน์ฝั่ง ซ้าย/ขวา |
| ตั้งค่าหุ่น | ความเร็วเดินตามเส้น _ ความเร็วเลี้ยว _ · หยิบกระป๋องด้วย อัลตราโซนิก/จับเวลา _ · เข้าถังอีก _ ถอยออก _ เข้ากรอบ START อีก _ วินาที |
| ภารกิจ | ทำภารกิจแยกขยะครบ 8 กระป๋อง แล้วกลับจุดเริ่มต้น · ย้ายกระป๋องใบที่ _ · กลับจุดเริ่มต้นแล้วจอด |
| ทีละขั้น | ไปหยิบกระป๋องที่จุดวางกระป๋อง · ไปวางกระป๋องที่ถังสี _ · ไปที่ทางแยก แถว _ คอลัมน์ _ |
| ตรวจสอบ | สีกระป๋องใบที่ _ เป็น _ · เส้นทางไปได้ครบทุกที่ · แสดงแผนที่สนามบนจอ OLED |

## ตัวอย่างโปรแกรมแข่ง

```blocks
KrathokKidsBit.oledInit(OLED_Address.Addr_0x3C, true)
KrathokKidsBit.setSensorCal([929, 1667, 1514, 1362, 1273, 969, 595, 558], [3724, 3833, 3829, 3830, 3814, 3782, 2312, 2450])
KrathokKidsBit.armSetup(Kids_Servo.S0, 175, 5, Kids_Servo.S1, 90, 20)
WasteSort.setObstacle(Waste_Row.R1, Waste_Col.C4)
WasteSort.setObstacle(Waste_Row.R2, Waste_Col.C3)
WasteSort.setObstacle(Waste_Row.R3, Waste_Col.C5)
WasteSort.setObstacle(Waste_Row.R4, Waste_Col.C2)
WasteSort.setCanColors(Waste_Color.White, Waste_Color.Black, Waste_Color.White, Waste_Color.Black, Waste_Color.White, Waste_Color.Black, Waste_Color.Black, Waste_Color.White)
WasteSort.showMap()
KrathokKidsBit.waitForButton(Kids_Button.A)
WasteSort.runMission()
```

## ขั้นตอนในวันแข่ง

1. **สอนเซ็นเซอร์** ด้วยบล็อก "สอนเซ็นเซอร์" ของ KrathokKidsBit แล้วจดค่าไปใส่ "ตั้งค่าเซ็นเซอร์" (ใช้เซ็นเซอร์ช่อง 0-5 เป็นเส้นกลาง ช่อง 6-7 เป็นเซ็นเซอร์ทางแยก ตามค่ามาตรฐาน)
2. **ตั้งค่าแขนกล** ให้มุมก้ามและแขนตรงกับหุ่นของตัวเอง
3. ดูสนามจริง แล้วใส่ **ตำแหน่งสิ่งกีดขวาง 4 ชิ้น** และ **ลำดับสีกระป๋อง** ที่กรรมการสุ่ม
4. กด **แสดงแผนที่สนามบนจอ OLED** ตรวจว่าตำแหน่งตรงกับสนามจริง มุมขวาล่างต้องขึ้น `OK` (ถ้าขึ้น `NO` แปลว่าไม่มีทางไป)
5. วางหุ่นในกรอบ START **หันหน้าลงสนาม** (ไปทางจุดวางกระป๋อง) กดปุ่ม A

## การปรับจูน

- **หยิบกระป๋อง**: แบบอัลตราโซนิก (Trig P1 Echo P2) หุ่นเดินตามเส้นจนกระป๋องใกล้กว่าค่าที่ตั้งแล้วหนีบ ถ้าไม่มีอัลตราโซนิกให้เลือกแบบจับเวลา
- **เข้าถัง**: หุ่นหยุดเมื่อเซ็นเซอร์ทางแยกเจอขอบถัง ถ้ากระป๋องยังไม่เข้าไปในพื้นที่ถัง ให้เพิ่มค่า "เข้าถังอีก"
- **ถอยออก**: ถ้าหุ่นกลับหลังหันแล้วชนกระป๋องในถัง ให้เพิ่มค่า "ถอยออก"
- **เข้ากรอบ START**: ต้องอยู่ในกรอบทั้งตัว ปรับค่า "เข้ากรอบ START อีก"
- ถ้าเลี้ยวที่ทางแยกไม่แม่น ปรับ KP KD ด้วยบล็อก "ปรับความไว" ของ KrathokKidsBit

## วิธีหาเส้นทาง

แผนที่เป็นตาราง 4 แถว × 5 คอลัมน์ หุ่นจำว่าอยู่ทางแยกไหนและหันทิศไหน ทุกครั้งที่ต้องไปที่ใหม่
จะคำนวณเส้นทางที่ใช้เวลาน้อยที่สุด (คิดระยะทางและจำนวนครั้งที่เลี้ยว) โดยไม่ผ่านทางแยกที่มีสิ่งกีดขวาง
แล้วสั่ง "เดินตามเส้นไปจนเจอทางแยก _ ครั้ง" และ "เลี้ยวจนเจอเส้น" ให้เอง
เวลาเลี้ยวจะนับเส้นที่กวาดผ่านด้วย เช่น กลับหลังหันที่ทางแยกสี่แยก = เลี้ยว 2 ครั้ง
